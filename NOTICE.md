# Notice

These skills are new text. They use ideas, steps and some structure from the projects below. All three use the MIT License.

| Skill | Source | What we used |
|---|---|---|
| `grill-me` | [mattpocock/skills](https://github.com/mattpocock/skills) `grilling` | Decision tree, rounds over the frontier, a recommended answer for each question, facts versus decisions |
| `grill-me` | [pstack](https://github.com/backnotprop/pstack) `interrogate` | State the intent first |
| `spec` | [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `spec-driven-development` | Assumptions list, success criteria, spec template, three-tier boundaries |
| `spec` | pstack `architect` | Ground first, design it twice, compare interface depth, scrap a wrong design |
| `build-plan` | agent-skills `planning-and-task-breakdown`, `incremental-implementation` | Vertical slices, task template, task size, checkpoints, scope and simplicity rules |
| `build-plan` | pstack `principle-sequence-verifiable-units` | One verified unit at a time, commits ordered as proof |
| `tdd` | agent-skills `test-driven-development` | Red, green, clean up. Prove-it pattern for bugs. Test state, not calls |
| `tdd` | pstack `tdd`, `principle-test-behavior-not-implementation` | Fail for the right reason, tests that can fail, no test is better than a bad test |
| `security-hardening` | agent-skills `security-and-hardening` | Always, ask first and never lists, checklist, secret check |
| `full-review` | agent-skills `code-review-and-quality` | Five axes, tests first, severity labels, honest review |
| `full-review` | pstack `blast-radius`, `principle-prove-it-works` | Look past the diff, the one key fact, levels of proof |

pstack is a port of Poteto's pstack for Cursor.
